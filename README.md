## Backend

Chắc cần cài thêm môi trường SDK java để chạy backend( với text editor như VSCode, ...).
Thường thì môi trường có sẵn nên không cần lo ( với các bản IDE như IntelliJ, ...).

Start server trong hàm main trong BackendApplication.java, server sẽ được port với localhost:8080.
Lưu ý: nhớ chỉnh lại config trong file application.properties về phần db để hoạt động đúng nhé (những phần liên quan đến db thôi nhé).
